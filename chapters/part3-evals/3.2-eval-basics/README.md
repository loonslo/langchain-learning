## 为什么做这个 gate

“准确率提升了”如果没有分母，就是一句空话。基础评测最容易出这些错：

- 应拒答的题没单独统计；
- 没有关键词的题被算成 0 分；
- 一道题调用异常，整批评测中断；
- 分母写错，百分比看起来漂亮但不可核对；
- 评测集被 `evaluate` 修改。

这个 gate 用假 `ask_fn` 和固定评测集，验证指标口径和异常行。

## 任务

实现 `gate/starter.py` 的两个函数：

| 函数 | 你要交付的行为 |
|---|---|
| `looks_like_refuse` | 命中任一拒答提示词返回 True；非字符串抛 `ValueError` |
| `evaluate` | 逐题调用；返回 rows + 拒答/关键词分子分母与准确率 |

关键口径：

- 空评测集 -> 全 0，`rows=[]`。
- `should_refuse=True` 的题只进拒答指标。
- 应答题没有 `keywords` -> 跳过关键词统计，不占分母。
- 关键词**全部**出现才算命中。
- `ask_fn` 抛异常：该行 `error`，`refused=False`，仍计入对应分母。
- 不修改 `eval_set`。

## 故障注入（必须亲手触发）

| # | 注入 | 期望 |
|---|---|---|
| 1 | 正常答案含拒答词 | `looks_like_refuse=True` |

## 概念地图

- **拒答正确率**：防幻觉底线；只对应拒答的题。
- **关键词命中率**：粗粒度正确性；只对有关键词的题。
- **分母**：每个指标都要能说清 X/Y；跳过的题不能算失败。
- **异常行**：调用失败要记录并保留分母，避免“失败被静默剔除”。
- **局限**：关键词匹配不懂同义/否定，需要 LLM Judge 补充。

## 边界

- gate 用假 `ask_fn`，不验证真实 RAG 质量。
- 关键词/拒答规则都是粗判；语义正确性见 3.3。
- 评测集质量见 3.4/3.5。

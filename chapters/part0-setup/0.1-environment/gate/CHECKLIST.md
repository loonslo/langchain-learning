# 0.1 环境与工具 · 清单验收

本章没有可闭卷验收的代码接口，用清单核对环境是否真的可用。

## 步骤

- [ ] 用 `python --version` 确认解释器版本，记录实际版本。
- [ ] 创建/激活 `.venv`，安装 `requirements.txt`。
- [ ] 运行 `python tools/run_chapter.py 1.1`，确认能完成一次最小调用（或明确记录缺少的 API key）。
- [ ] 运行 `python tools/check_course_links.py`，确认断链 0。
- [ ] 记录操作系统、Python、依赖安装方式、失败项。

## 通过标准

- 环境命令有实际输出，不是“应该可以”。
- 缺少密钥/依赖时明确写“未验证”，不把跳过当通过。
- 证据可复制执行。

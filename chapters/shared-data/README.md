# 共享资料

多个章节共用的示例文档和评测集。路径由根目录 `common.py` 提供（`SAMPLE_DOC`、`LONG_DOC`、`SHARED_DATA_DIR`），脚本不依赖工作目录。

| 文件 | 用途 | 由谁使用 |
|---|---|---|
| `test_doc.txt` | 短文档（约 800 字节，LangChain、RAG、LangGraph、向量数据库各一段）。评测集的问题和标准答案都基于它，请不要改动 | 2.2、2.3、2.5、2.9–2.10、3.2–3.7、5.1 |
| `long_article.txt` | 长文章（约 8.7KB），文档够长，切分与检索策略的差异才看得出来 | 2.1、2.7、2.8、2.11 |
| `eval_set.json` | 第一批评测样本（15 条） | 3.4 生成；3.5 读取 |
| `eval_set_full.json` | 完整评测集（25 条），整条评测线的单一数据源 | 3.5 生成；3.2、3.3、3.6、3.7 读取 |
| `failures.json` | 候选版的失败样本，含问题、标准答案和召回上下文 | 3.7 加 `--write-failures` 生成；3.10 读取 |

后三个文件是运行章节脚本时生成的，不进入 Git；按 3.4 → 3.5 → 3.7 的顺序运行即可得到。
5.8 的测试文档是自带的另一份合成资料，位于该章目录，与这里无关。
